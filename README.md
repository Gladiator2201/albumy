# Albumy rodzinne – Wszystko co Nasze

Siatka okładek albumów Google Foto ze stron Roku (2005–2021) i pokazów na GitHub Pages.
Najechanie (na telefonie dotknięcie) pokazuje komiksowy dymek z tytułem, kliknięcie otwiera album.
Przycisk „Lista albumów” otwiera wyskakującą listę tytułów.

Gość widzi tylko zestaw przekazany w łączu (`?z=…`).
